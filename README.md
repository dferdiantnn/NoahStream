# 🛳️ Noah Stream - Pro Multi-Stream & Market Intelligence Hub

Noah Stream is an advanced, ultra-responsive multi-stream monitoring platform with integrated live YouTube Discovery, TradingView candlestick charts, and the **Noah Algo EA** real-time bullish/bearish market intelligence engine.

---

## 🌟 Core Features

- **🚀 Live Finder (Auto-Discovery Engine)**: Real-time YouTube live stream scraper targeting trending market keywords.
- **📐 Modular 2×2 Landscape Pin Modes**: Pinned hero stream dynamically occupies a 2×2 modular grid block.
- **🎮 Drag & Drop Reordering**: Seamlessly reorder active stream cards via drag handles.
- **⚡ Ultra-Compact Stream Health Bar**: Single-line status monitor displaying stream state, resolution, buffer speed, active live viewer counts, and degraded signal alerts.
- **📊 Market Intelligence & EA Engine**: Real-time TradingView XAU/USD Candlestick Chart (RSI, MA, MACD) & Noah Algo EA Engine.
- **🛡️ Auto-Cleanup**: Automatically detects ended or unresponsive streams and cleans them from the grid.

---

## 🚀 Quick Start
```bash
python3 server.py
```
Open `http://localhost:3000` in your browser.
